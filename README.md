# Gymbro

A web-first daily workout companion.

## Product direction

Gymbro is being built as a responsive website first, with the architecture intentionally kept portable for a future native iOS/Android app.

### MVP goals

- Show a focused workout for today.
- Present exercises with sets, reps and rest.
- Let the user mark exercises complete.
- Keep the workout engine separate from the interface.
- Grow toward personalized daily workout generation based on goals, equipment, preferences and training history.

## Local development

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Roadmap

1. Daily workout experience
2. Exercise database + filters
3. User onboarding and preferences
4. Workout generation engine
5. Set/weight/reps logging
6. History and progression
7. Accounts + cloud sync
8. Native mobile client
